# Namespaces and Autoloading — Student Activity Guide

## Course Context

This activity is designed for the **comprehensive Weeks 11–17 semester template** and maintains the core learning objectives from previous standalone assignments while integrating with the complete Laravel development environment.

## Primary Learning Objectives

- Select and implement an original project domain
- Create three properly organized class files (Model, Service, Report)
- Demonstrate understanding of PHP namespaces and Composer PSR-4 autoloading
- Implement class aliasing using `use ... as ...` syntax
- Generate and display two domain-specific record instances

## Implementation Guidelines

### Location and Structure

**Important Distinction:** Your project development occurs within `app/StudentProject/` directory. The instructor's Week 11 demonstration utilizing the `Book` classes should remain unchanged.

### Execution and Verification

Display your implementation using:
- **Terminal Command:** `php artisan oop:project`
- **Browser Interface:** Navigate to `/my-project`

### Continuity Requirement

**Critical:** The domain selected in this activity must remain consistent throughout the entire semester (Weeks 11-17). Topic changes require explicit instructor approval.
