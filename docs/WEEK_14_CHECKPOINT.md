# Week 14 — Pre-Final Examination Period

The institutional syllabus designates this week for **Pre-Final Examination**. This template intentionally provides no supplementary lesson material or examination content during this period.

## Review Guidelines

Students should conduct comprehensive review of material from Weeks 11–13 using the following resources:

- [Week 11: Namespaces and Autoloading](WEEK_11.md)
- [Week 12: Database Operations with PDO](WEEK_12.md)
- [Week 13: MVC Application Development](WEEK_13.md)

Follow all official examination procedures and schedules as communicated through your institution's Learning Management System (LMS).

## Suggested Self-Assessment Topics

The following topics provide a framework for self-directed review (not an official examination):

- **Namespaces:** Articulate the distinction between `namespace` declarations and `use` statements
- **Autoloading:** Identify and explain the PSR-4 prefix configuration in `composer.json`
- **Database Security:** Locate and describe a PDO prepared statement implementation
- **CRUD Operations:** Define Create, Read, Update, and Delete operations
- **MVC Architecture:** Trace a complete request flow: Route → Controller → Service/Model → View
